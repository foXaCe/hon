# FAQ

## Quels appareils sont supportés ?

Tous les appareils Haier, Candy et Hoover intégrés dans l'application mobile hOn : climatisation, pompes à chaleur, lave-linge, sèche-linge, fours, lave-vaisselle, caves à vin, purificateurs d'air, chauffe-eau.

## Faut-il l'application mobile ?

Oui — vos appareils doivent être contrôlés par l'application hOn avant de pouvoir être ajoutés à Home Assistant.

## L'intégration est-elle gratuite ?

Oui, le code est open source sous licence MIT.
